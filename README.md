# Курсовая работа: Приложение для анализа транзакций

## Описание
Приложение анализирует Excel-файл с транзакциями (`data/operations.xlsx`), генерирует JSON-ответы для веб-страниц, предоставляет сервисы поиска и формирует отчеты.

## Реализованные задачи
### Веб-страницы
- **Главная**: Генерирует JSON с приветствием, тратами по картам (с кешбэком), топ-5 транзакций, курсами валют и ценами на акции.

### Сервисы
- **Простой поиск**: Ищет транзакции по подстроке в описании или категории.
- **Поиск по телефонным номерам**: Находит транзакции, содержащие в описании мобильные номера.

### Отчеты
- **Траты по категории**: Возвращает траты по заданной категории за последние 3 месяца. Реализован декоратор для сохранения отчета в JSON-файл.

## Запуск
1. Установите зависимости: `pip install pandas openpyxl pytest requests`.
2. Запустите демонстрацию: `python -m src.main`
